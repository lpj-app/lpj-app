## About

I build cloud-based web and mobile applications end to end: databases, backend, APIs and frontend.

I also run my own infrastructure: all VMs are configured declaratively with **NixOS**, running a **k3s** cluster with CI/CD pipelines, connected through a **mesh VPN** for service traffic and a separate **admin VPN** for management access. All of my products and services are hosted on it, under **[LPJ IT-Solutions](https://github.com/lpj-it-solutions)**.

Currently: apprenticeship as *Fachinformatiker Anwendungsentwicklung* (until 02/2027) and B.Sc. Business Informatics at Hochschule Mainz (since 09/2025).
